✚ MediVault Votre santé, en sécurité, dans un seul dossier

Socle Angular — Équipe Keystone

Application front-end de MediVault. Elle consomme les API des microservices via l'API Gateway (http://localhost:8080/api/**) avec un jeton JWT Keycloak.

  • Utilisateurs inscription, connexion, profil, notifications (commun)
  • Dossier médical dossier patient, consultations, accès (Eya)
  • Ordonnances rédaction avec alertes, liste (Amine)
  • Médicaments catalogue, interactions, retrait (Fedia)
  • Pharmacie recherche par code, délivrance, historique (Aziz)
  • Analyses analyses à traiter, saisie, mes résultats (Taha)
  • Rendez-vous agenda, prise de rendez-vous (Yazid)
